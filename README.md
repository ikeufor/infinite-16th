# ♾️ INFINITE 16th Anniversary Frame

Sixteen years of memories deserve a frame of their own.

This fan-made website lets you place your favourite photo inside a special INFINITE 16th Anniversary frame and save it as a keepsake for the celebration.

## Features

✨ Upload your own photo  
✨ Download your finished photo  
✨ Works on desktop and mobile
